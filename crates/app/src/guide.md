# Welcome to Trailboard

Every page is a live card on one big board. A link you open lands **beside** the page it came from, so each search leaves a trail you can see.

## Getting around

- **Pan:** drag the board or scroll · **Zoom:** Ctrl + scroll
- **Next card:** h j k l or the arrows · **Fit all:** Shift+F
- **Use a page:** click it or Enter · **Back to the board:** Esc
- **Read one page full-window:** Tab

## Opening pages

- **New card / address bar:** Ctrl+T / Ctrl+L
- **Find anything** (cards, history, commands): Ctrl+K
- **Open beside the current card** from Ctrl+K, Ctrl+H or the address bar: Shift+Enter
- **Follow a link by keyboard:** f, then its label
- **Close / reopen:** Ctrl+W / Ctrl+Shift+T

## Keeping it tidy

- **Note / sticky note:** N / Shift+N
- **Trails list:** B · **Lay out:** T · **Fold a trail:** S
- **New space** (a separate board): Ctrl+Shift+N

**?** shows every shortcut, **Ctrl+,** the settings. This is a note: click to edit it, Ctrl+W to close it.
